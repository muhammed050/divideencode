5. M2 — ENTROPY-CODED TOKEN STREAMS

After LZ2 is proven correct, add:

literal stream
length stream
distance stream
repeat stream / flags

Each stream gets its own canonical Huffman model.

Do not Huffman-code the complete serialized LZ blob.

The whole point is to allow the different symbol distributions to be modeled independently.

Example:

Literals:
  256-symbol alphabet

Lengths:
  length-code alphabet

Distances:
  distance-code alphabet

Repeat offsets:
  tiny dedicated alphabet

Reuse the existing validated canonical Huffman implementation where possible.

6. DO NOT USE FIXED-WIDTH DISTANCES

This is critical.

The old design pays fixed-width bytes for distance information.

V2 must entropy-code distance symbols.

Use a scheme inspired by DEFLATE/zstd:

distance class
+
extra bits

and:

length class
+
extra bits

This allows common short distances and common lengths to become extremely cheap.
